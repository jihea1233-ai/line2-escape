## 3. 미션 바꾸기 — `MISSIONS` 한 곳만 고치면 됩니다

파일을 메모장이나 텍스트 편집기로 열고, `<script>` 바로 아래 **`MISSIONS = [ ... ]`** 를 찾으세요.
그 안의 객체 하나가 역 하나입니다. 역을 추가하면 진행바·클리어 화면·타이머가 자동으로 늘어납니다. 화면 코드는 건드릴 필요 없습니다.

```js
{
  id: 'hongdae',                                  // 고유 이름 (저장 키, 역마다 달라야 함)
  tag: 'sample',                                  // 'sample' → 화면에 [Sample]/[샘플] 표시
  code: '239',                                    // 안내판의 역 번호
  station: { en: 'Hongik Univ.', ko: '홍대입구' },
  missionTitle: { en: 'The Busker\'s Chord', ko: '거리의 화음' },
  story: { en: '...', ko: '...' },                // 이야기 (줄바꿈 \n 가능)
  clue: { en: '...', ko: '...' },                 // 승강장에서 보이는 단서
  image: '',                                      // 'photos/hongdae.jpg' 또는 비워 두기
  photoCaption: { en: 'Exit 9, night', ko: '9번 출구, 밤' },
  question: { en: '...', ko: '...' },
  type: 'text',                                   // 'text' 또는 'choice'
  placeholder: { en: 'Type a number', ko: '숫자를 입력' },
  answers: ['239', '2-3-9'],                      // 정답 여러 개 허용
  hints: [ { en: '...', ko: '...' }, { en: '...', ko: '...' } ],
  success: { en: '...', ko: '...' }
}
```

**객관식으로 만들려면** `type: 'choice'` 로 바꾸고 `answers` 대신 아래를 넣습니다.

```js
  type: 'choice',
  choices: [
    { en: 'Green gate · Line 2', ko: '초록 게이트 · 2호선' },
    { en: 'Orange gate · Line 3', ko: '주황 게이트 · 3호선' }
  ],
  correct: 1,          // 정답 보기의 순서 (0부터 시작)
```

### 정답 처리 규칙
- 대소문자, 띄어쓰기, 마침표·하이픈은 무시됩니다. (`No. 211` = `211`)
- 끝에 붙은 「번·호·역」도 무시됩니다. (`211번` = `211`)
- 정답 후보를 여러 개 넣어 두면 영어·한국어·숫자 표기를 모두 받아 줄 수 있습니다. 외국인에게 특히 중요합니다.

### 사진 넣기
1. 사진을 HTML 파일과 **같은 폴더**에 둡니다. (예: `documents/photos/seongsu.jpg`)
2. `image: 'photos/seongsu.jpg'` 처럼 적습니다.
3. 비워 두면 지금처럼 점선 자리 표시자가 나옵니다.

## 4. 언어

- 오른쪽 위 **EN / KO** 를 누르면 화면 전체(이야기·단서·힌트·버튼)가 즉시 바뀝니다. 진행 상황과 입력 중이던 답은 그대로 남습니다.
- 모든 문구는 `MISSIONS` 와 `UI` 두 곳에 `{ en, ko }` 로 들어 있습니다. `UI` 는 버튼·안내 같은 고정 문구입니다.
- 역 이름판은 실제 지하철 안내판처럼 **한글 + 영어를 항상 함께** 보여 줍니다. 외국인도 역을 찾을 수 있게 하려는 의도입니다.

- 실제 배포 시에는 파일을 웹에 올려 링크로 공유 (지금 파일은 그대로 올려도 동작합니다)

## 6. 검증 결과

- HTML 구조 검사: 오류 없음 (태그 불일치 0)
- JavaScript 문법 검사(esprima): 통과

  - 언어 전환 시 진행·입력값 유지, 새로고침 복원, 진행바·타이머·통계 표시
